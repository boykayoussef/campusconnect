# Demo Workflow

1. Run `npm run seed:demo` in `server/`.
2. Start the backend with `npm start`.
3. Start the frontend with `npm run dev`.
4. Log in as the demo student and browse the event feed.
5. Open an event and RSVP.
6. Log in as the approved club leader and open **My Events → Registrants**.
7. Confirm or cancel the student's registration.
8. Log in as the admin and review users, approve/reject club leaders, change roles, and remove events.

This workflow demonstrates the main end-to-end student, club-leader, and admin requirements from the project brief.
